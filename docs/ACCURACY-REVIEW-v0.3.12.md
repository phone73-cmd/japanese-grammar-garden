## 우선 수정: 복수 정답 3문항

`content[25].questions`의 **0부터 시작하는 저장 인덱스**입니다. 무작위로 출제되므로 화면의 13·14·15번 문제를 뜻하지 않습니다.

| 인덱스 | 문항 | 현재 정답 | 함께 맞는 답 |
|---|---|---|---|
| 12 | 大阪＿＿行きます。 | へ | に |
| 13 | 友だちと駅＿＿行きます。 | へ | に |
| 14 | 家＿＿帰ります。 | に | へ |

국제교류기금 『いろどり』 입문 18과는 이동동사에 쓰는 へ를 に로 바꿀 수 있음을 설명합니다. 단일 정답 문제에서는 유효한 대안을 오답으로 넣지 않도록 생성 규칙을 고쳐야 합니다. 韓国＿＿来ました의 ‘한국에서 왔다’는 출발점 から를 묻는 다른 사례이므로 같은 오류로 묶지 않았습니다.

수정 때는 문항 인덱스를 유지하고, 기존 오답·출제 이력·진행 중 퀴즈에 저장된 선택 답안이 선택지 변경으로 다르게 해석되지 않는지 검증해야 합니다. 수정 전 기록의 점수를 임의로 재계산하지 않습니다.

## 표현 개선 권고 7유형

아래는 명백한 문법 오류 7개라는 뜻이 아닙니다. 제시 문장은 교체 방향을 보여 주는 편집안이며 앱에 반영하지 않았습니다. 새 문장 확정 시 읽기·번역·단원 적합성·한자 연결 및 파생 문제를 함께 대조합니다.

### G02 · 경험 표현의 특별한 문맥 부족

문법 형태를 틀렸다고 단정하지 않음. 평범한 행동에 무엇을 경험했는지 드러내는 목적어·장소·상황을 추가.

- 45과 / learning_example[4]: 本を読んだことがあります。 → 책을 읽어 본 적이 있습니다.
- 45과 / learning_example[5]: 水を飲んだことがあります。 → 물을 마셔 본 적이 있습니다.
- 45과 / learning_example[6]: まだパンを食べたことがありません。 → 아직 빵을 먹어 본 적이 없습니다.
- 45과 / learning_example[11]: 一人で音楽を聞いたことはありません。 → 혼자 음악을 들어 본 적은 없습니다.

보강 방향 예: **日本のお茶を飲んだことがあります。**

### G03 · 이동동사 ています의 해석 명료화

가거나 돌아간 뒤의 상태와 이동 진행을 구분하도록 문맥·표현 보완. 현재 번역을 모든 상황에서 틀렸다고 단정하지 않음.

- 28과 / assessment_context[1]: 今、駅へ行っています。 → 지금 역에 가고 있습니다.
- 28과 / assessment_context[6]: 今、家へ帰っています。 → 지금 집으로 돌아가고 있습니다.
- 28과 / assessment_context[27]: 昨日の今ごろは駅へ行っていました。 → 어제 이맘때에는 역에 가고 있었습니다.
- 28과 / assessment_context[30]: 昨日の今ごろは家へ帰っていました。 → 어제 이맘때에는 집으로 돌아가고 있었습니다.

보강 방향 예: **今、駅に向かっています。**

### G04 · 시설 치환으로 질문 대상 불명확

장소마다 영업·입장·체크인 대상이 다르므로 슬롯을 분리. 실제 공항 운영 사실을 검증한 문장이 아님.

- 58과 / learning_example[4]: 駅は何時からですか。 → 역은 몇 시부터입니까?
- 58과 / learning_example[5]: ホテルは何時からですか。 → 호텔은 몇 시부터입니까?
- 58과 / learning_example[8]: 空港は今日は休みですか。 → 공항은 오늘 쉬는 날입니까?

보강 방향 예: **ホテルのチェックインは何時からですか。**

### G05 · 금지 표현의 이유·상황 부족

특정 상황에서는 가능한 문장이지만 독립 예문은 실제 규칙이나 상황을 드러내도록 교체 권고.

- 34과 / learning_example[8]: 一人で写真を見てはいけません。 → 혼자 사진을 보면 안 됩니다.
- 34과 / learning_example[9]: 一人で日本語を話してはいけません。 → 혼자 일본어를 말하면 안 됩니다.

보강 방향 예: **図書館では大きな声で話してはいけません。**

### G06 · 겸양어가 향하는 상대의 문맥 부족

사람·기관의 상대를 방문하는 상황이라면 가능. 일반 장소 이동을 언제나 伺う로 바꾸는 것으로 오해하지 않게 보완.

- 49과 / learning_example[4]: 明日、駅に伺います。 → 내일 역에 찾아뵙겠습니다.
- 49과 / learning_example[5]: 明日、ホテルに伺います。 → 내일 호텔에 찾아뵙겠습니다.

보강 방향 예: **明日、先生のところに伺います。**

### G07 · 분실자와 습득자의 발화 역할 구분

届ける는 가져다주거나 신고·전달하는 뜻. 분실물을 찾는 말로 오해하지 않게 습득자 문맥 추가.

- 59과 / learning_example[10]: 財布はどこに届ければいいですか。 → 지갑은 어디에 가져다주면 됩니까?
- 59과 / learning_example[11]: 写真はどこに届ければいいですか。 → 사진은 어디에 가져다주면 됩니까?

보강 방향 예: **財布を拾いました。どこに届ければいいですか。**

### G08 · 한국어 번역의 높임·자연스러움

의미 오류로 분류하지 않음. 저는 + 평서 한다 혼합과 장황한 일을 별로 하지 않는다 표현 정리.

- 29과 / learning_example[10]: 私はあまり手紙を書かない。 → 저는 편지를 쓰는 일을 별로 하지 않는다.
- 29과 / learning_example[11]: 私はあまり音楽を聞かない。 → 저는 음악을 듣는 일을 별로 하지 않는다.

보강 방향 예: **저는 편지를 별로 쓰지 않습니다.**

## 적용 원칙·남은 확인

1. 우선 복수 정답 3문항과 생성 규칙을 수정하고 같은 유형 재발 검사를 추가합니다.
2. 문맥 보강은 대표 위치만 임의 변경하지 않고 관련 템플릿·평가 문맥·복습 단원 재사용·검색 색인까지 함께 반영합니다.
3. 기존 단원 ID, 질문 인덱스, 학습 기록, 오답, 진행 중 퀴즈 및 JSON/IndexedDB 백업을 보호합니다. 기존 내용 보존용 fixture는 언어 오류를 고치지 못하게 하는 제약으로 오해하지 않으며, 승인된 수정과 무관한 데이터 변화가 없는지 대조합니다.
4. 일반적인 상황에서 쓰이는 표현을 특정 문맥의 가능성만으로 무조건 틀렸다고 단정하지 않습니다. 이동 ています·겸양어 伺う는 문맥 보강 권고입니다.
5. 사용자가 실사용 완료를 보고한 사실과, 앱에 반영된 정확도 수정·전체 언어 정밀 감수 완료는 별도로 표시합니다.
