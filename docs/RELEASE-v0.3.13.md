## 기록과 이어 풀기

- localStorage 키·IndexedDB 보호 사본·schema 1 백업 형식을 바꾸지 않았습니다. 완료된 시험 점수·시도 횟수는 재계산하지 않습니다.
- 새 퀴즈는 출제된 문제·보기·해설을 UI 세션에 함께 저장합니다. 업데이트 후에도 선택한 번호가 다른 보기로 바뀌지 않습니다.
- 이전 버전에서 진행 중이던 교정 대상 문제는 기존 문항 내용을 복원합니다. に/へ가 함께 들어 있던 이전 3문항은 두 유효 답을 모두 인정합니다. 이전 OX 제시 답 역시 같은 기준으로 판정합니다.
- 이전 문장 조립은 기존 문장 조각·선택 상태를 검증해 그대로 이어서 풀 수 있습니다. 새 연습은 교정된 예문을 사용합니다.
- 잘못된 문제 스냅샷은 거부하며 기존 로컬 백업에서 복구합니다. 저장 실패 안내와 완료 기록 중복 방지 조건을 유지합니다.
