# iPhone Safari·홈 화면 PWA 인수 검사

v0.3.1-dev · 다음 항목의 실제 iPhone 결과는 **미확인**입니다. 원격 Chrome 검사나 Node 모의 검사를 실기기 결과로 대체하지 않습니다.

각 항목을 Safari와 홈 화면 앱에서 따로 검사합니다. 먼저 문법·한자 JSON을 각각 내보내 기기 밖에 보관합니다.

1. 버전 v0.3.1-dev 확인, 기존 점수·오답·진행 중 시험 수량 비교.
2. 기존 1·6·7과 시험 이어 풀기, 답 선택 후 새로고침, 문제·선택·해설 동일 확인.
3. 새 2·26·48·54·60과 학습·시험 시작, 새로고침 복구, 10문제 완료 기록 한 번.
4. 한자 카드 → 새로고침 → 같은 카드. 상단 뒤로 → 목록. 퀴즈 중 뒤로 스와이프 → 계속/나가기 각 확인.
5. 문법·한자 오답 1개와 여러 개를 각각 재시험. 정답은 오답 목록에서 해소되고 다른 단어의 오답은 유지.
6. 오늘 복습이 0개일 때 안내, 1개와 여러 개일 때 정해진 개수 출제. 정답 다음 일정 1/3/7/14일, 오답 즉시 재복습.
7. OX와 문장 조립 중 일부 선택 → 새로고침 → 그대로 이어짐. 문장 조립 되돌리기/초기화/정답/오답.
8. 온라인 최초 캐시 설치 후 비행기 모드. 앱 종료·재실행, 새 단원과 한자 데이터·자료 출처 화면 열기. 음성 지원은 기기별 별도 검사.
9. 앱을 연 상태에서 다음 버전 배포 → 업데이트 적용 → 답안·오답·기록 유지. 업데이트는 필수 캐시 설치 성공 후에만 활성화.
10. 다크모드 확인창 제목·설명·두 버튼, 밝기 70/100/120%, 6색 테마 확인.
11. 작은 화면·가로 화면·글자 확대에서 가로 잘림, 하단 버튼 가림, 확인창 내부 스크롤 확인. 한마디 뜻 표시 전환에서 버튼 위치 유지.
12. JSON 내보내기와 가져오기, 보호 사본 내보내기. 앱 강제 종료 후 기록과 보호 사본 재확인.
13. 홈 화면에 추가한 PNG 아이콘 확인. 삭제 후 재설치는 기록이 지워질 수 있으므로 검사 방법으로 사용하지 않습니다.

## 실기기 확인 후의 다음 단계
- 위 결과를 기록한 뒤 IndexedDB를 기본 저장소로 바꾸는 별도 마이그레이션을 검토합니다. 현재는 원래 localStorage 키와 IndexedDB 보호 사본을 함께 유지합니다.
