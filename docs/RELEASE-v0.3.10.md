## 실제 수량

- 기존 학습 예문 237개에 480개 추가: **717개**. 각 단원에 실제로 8개씩 추가하여 01·06·07과는 11개, 나머지는 12개입니다. 문자 단원은 단어 예시와 소리 비교를 포함하며 모든 항목이 완결된 문장인 것은 아닙니다.
- 여행 51~59과는 단원당 기존 1개+신규 2개, **총 27개 대화·108개 발화**. 이는 위 717개 학습 예문과 별도로 집계합니다. 원래 대화 36개 발화도 유지하고 로마자를 보강했습니다.
- **평가 전용 문장·단어 1,828개**를 학습 예문과 분리했습니다. 일반 문법 단원마다 최소 30개가 있고, 문자 단원은 기존 전체 문자·조합 문제은행을 유지합니다. 03과에는 별도 박자 문제도 추가했습니다. 판독·뜻·일본어 표현 선택으로 확장한 전체 등록 문항은 **6,950개**입니다. 이 수치는 서로 다른 상황 6,950개를 뜻하지 않습니다.
- 문형별 네 가지 기능(질문·부정·과거·대조·요청 등)과 어휘 변형을 조합한 자료를 포함합니다. 모든 문장을 서로 다른 독립적인 이야기로 작성했다는 의미는 아닙니다. 예문과 문제는 `scripts/build_practice.py`에서 재현합니다.

## 출제 방식

일반 시험은 계속 10문제입니다. 질문 방향이 달라도 같은 문장을 한 묶음으로 처리하며, 한 시험에서는 같은 묶음을 중복 선택하지 않습니다. 기존 문제의 뜻 선택·역방향·빈칸도 가능한 한 원래 예문으로 연결합니다. 종합평가는 앞선 9개 단원에서 최소 한 문제씩 선택하면서 동일 문장의 단원 간 중복도 제외합니다.

최근에 출제한 문장 묶음과 문제의 마지막 출제 회차를 문법 기록 `practiceHistory`에 저장합니다. 오래 출제하지 않은 묶음·문제를 먼저 고르고 같은 조건에서는 오답·미학습을 고려합니다. 충분한 새 묶음이 남아 있을 때에는 최근 묶음을 피합니다. 전체를 순환한 뒤에는 다시 출제될 수 있으며 영구적으로 반복을 금지하는 방식은 아닙니다. 이력은 새 시험을 시작할 때 저장하므로 중단한 시험도 노출한 문제로 취급합니다. 이어 풀기는 새 회차를 소비하지 않습니다.

오답 복습·오늘 복습은 기존 복습 정책을 유지하며 일반 출제 회차를 소비하지 않습니다. 반복을 줄이기 위해 필요한 오답 복습을 생략하지 않습니다.

## 보존 및 오류 처리

- 기존 1,430문제의 인덱스·내용·선택지, 237예문의 인덱스와 네 필드를 SHA-256으로 비교하여 동일함을 확인했습니다. 새 항목은 뒤에만 추가합니다.
- 기존 한자 625자 원본 및 연결 데이터, 단어·예문, 한자 학습 저장 형식을 변경하지 않았습니다.
- jgg.progress.v1 / jgg.session.v1 / jgg.session.backup.v1 / jgg.kanji.v1 / jgg.kanji.quiz.v1 / jgg.kanji.quiz.backup.v1 유지. schema 1 백업에 practiceHistory가 추가되며 새 필드 없는 옛 백업도 복원됩니다. IndexedDB 보호 사본에는 전체 기록을 계속 보관합니다.
- 출제 이력 저장 실패 시 이전 퀴즈와 회차를 유지하고 새 시험을 시작하지 않습니다.
- 기존 퀴즈는 문제 인덱스가 그대로이므로 복구할 수 있습니다. 조립은 늘어난 예문에서 최대 10개를 고르며, 실제 예문 번호와 검증용 참조 번호를 구분하도록 보완했습니다. 기존 조립 스냅샷은 그대로 사용합니다.
- 예문 음성은 제공된 히라가나를 일본어 ja-JP, rate .85로 읽습니다. 실제 합성음 품질은 기기에 따라 다릅니다.
