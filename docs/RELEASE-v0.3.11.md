## 데이터·사전 대조

총 **639자 = 기존 625자 + 신규 14자**. 추가 목록은 125→139자이며 새 ID는 기존 방식 `extra-{codepoint}`, stage 6, order 126~139입니다. 기존 625자의 ID·순서·단어·예문 파일 및 `kanji-enrichment.json`은 수정하지 않았습니다.

추가 글자: **並 券 召 届 探 滞 看 航 袋 許 護 販 軽 辛**.

- 14자의 한국 한자음·일본어 음독·훈독은 공식 EDRDG KANJIDIC2 2026-10-24 스냅샷에서 가져왔습니다. 사전 수록 훈독이 없는 券·航은 빈 목록을 유지합니다.
- 한국식 훈은 한국어 위키낱말사전의 개별 revision·timestamp·URL로 연결했습니다. 届·滞는 屆·滯의 훈을 사용하고 並/竝·届/屆·滞/滯·軽/輕의 표기 차이를 확인했습니다. 자체 추정 훈을 채우지 않았습니다.
- 대표 단어 **29개 연결**(한 카드 2~3개). JMdict 표기/읽기 제한 및 sense 제한을 대조했고 영어 뜻 근거를 남겼습니다. 한국어 번역은 자체 작성 초안입니다.
- 연결 문제는 同音의 다른 유효 표기(예: 並ぶ/列ぶ)를 오답 선택지에서 제외합니다.
- 현재 학습 예문 **717개**와 여행 대화 **108발화**에서 한자 연결 누락 **0자**. 제목·설명·문제은행·모든 복합어 전체의 모든 한자까지 포함한 목록이라는 뜻은 아닙니다.
- 자료 확보: `python scripts/fetch_kanji14_sources.py SOURCE_DIR`(기존 파일은 덮어쓰지 않음). 재현: `python scripts/build_kanji14.py SOURCE_DIR` → `python scripts/build_library.py SOURCE_DIR`. `scripts/requirements-kanji-audit.txt`의 mwparserfromhell==0.7.2 사용. 원본 사전·API 스냅샷은 외부 작업 폴더에 두고 앱에는 파생 연결 데이터만 배포합니다. 해시는 각 JSON에 기록합니다.

## 검색과 목록

`data/library-index.json`에 **2,886항목**을 생성합니다: 단원 60, 예문 717, 대화 108, 한자 639, 단어 1,304, 학습용 기능어·문형 58. 단어 수는 표기·읽기·뜻 조합 기준이며 단원별 예문 등은 중복 문장도 집계합니다.

히라가나/가타카나·반각/전각을 정규화하고 뜻·읽기·문형 별칭을 함께 검색합니다. 정확히 일치하는 결과를 우선합니다. 품사 필터, 더 보기, 검색어 지우기, Enter 시 키보드 닫기를 제공합니다. 일본어·뜻·읽기를 보여 주며 관련 단원과 해당 단어의 연결 가능한 한자를 각각 열 수 있습니다.

검색어·분류·표시 범위·이동 전 위치는 기존 UI 세션에 추가로 저장합니다. 학습 기록을 검색 상태로 대체하지 않습니다. 단원으로 이동했다 앱 뒤로가기로 돌아오거나 한자 카드를 닫아도 검색 화면을 유지합니다. 현재 자료는 외부 검색 API 없이 앱 안에서 검색합니다. 캐시 설치가 완료된 환경에서는 오프라인 검색이 가능합니다.

단어 품사는 JMdict의 해당 표기/읽기 제한과 sense별 품사를 대조합니다. 기능어·의문사·문형·인사는 명시적인 학습용 분류입니다. 복수 품사에 포함되는 단어가 있고, **5항목은 분류 확인 중**으로 남깁니다. 모호한 항목을 어미만 보고 자동 분류하지 않습니다. 캐시된 사전 파생 자료에는 기존 CC BY-SA 4.0 출처·조건을 유지합니다.

## 추천 기준

- 실제 미해결 오답 → 오늘까지의 복습 예정 → 충분한 시험 기록의 낮은 정답률 순서.
- 단원 정답률은 단원 시험·OX 중 `correct`와 `total`이 남아 있는 기록 10문제 이상일 때만 합산합니다. 복수 단원 오답 시험을 첫 단원 정답률로 잘못 합산하지 않으며, 옛 점수만으로 정답 수를 추정하지 않습니다.
- 문자·한자는 실제 오답·복습 일정과 연속 정답으로 안내합니다. 카드 방문/듣기 횟수나 연속 정답÷방문 횟수를 누적 정답률로 사용하지 않습니다. 들었을 뿐인 글자를 취약하다고 판정하지 않습니다.
- 다음 단원은 정규 단원 시험 80점 통과 여부와 최근 학습 단원으로 선택합니다. OX 점수를 단원 통과로 취급하지 않습니다. 기록이 없으면 1단계 시작을 안내하고, 모두 통과했다면 복습을 안내합니다.
- 기록이 부족한 곳에는 부족하다고 표시합니다. 추천을 계산하며 기존 기록을 수정하지 않습니다.
