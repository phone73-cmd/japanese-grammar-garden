## 검증 중 보완한 항목 (v0.3.1-dev)

- 완료 화면의 재연습 버튼이 OX·조립·복습 종류를 유지하도록 수정.
- 해소된 오답도 이력은 남으므로 ‘아직 기록이 없습니다’ 대신 ‘복습할 오답이 없습니다’로 안내.
- 한자 오답 중복 집계 정리, OX 제시 답의 참/거짓 균형, 조립 완료 세션 길이 검증.

## 남은 검사

- 실제 iPhone의 터치·뒤로 스와이프·작은 화면·가로 화면·글자 확대.
- 실제 Safari 및 홈 화면 PWA의 최초 설치·비행기 모드·강제 종료·음성·파일 가져오기.
- 기기별 IndexedDB 저장 제한 및 보호 사본 복원 파일 가져오기.
- 독립 전문가 콘텐츠 감수.

Node 모의 검사 23개는 실제 브라우저 기록과 별도로 관리합니다.
