# 🌸 일본어 문법정원 (Japanese Grammar Garden)

**개발 브랜치 버전: v0.2.4-dev (main 배포 버전: v0.2.3) (한자 화면 이동·새로고침 안정화)**

## 한자 학습 v0.2.0 (2026-10-23)

- **학습 메뉴 확장**: 기존 하단 4개 탭 유지, '학습' 화면에 한자 학습 진입 버튼 추가. 기본 100자 + 확장 400자, 전체 5단계×100자
- **한자 카드**: 한자/한국어 뜻, 음독/훈독, 대표 단어 읽기·뜻, 예문 일본어/히라가나/번역, 뜻·발음 숨김, 일본어 음성(ja-JP, rate 0.85)
- **퀴즈**: 단계별 10문제, 단어 읽기·뜻 4지선다, 즉시 해설 및 80점 통과 기준; 읽기 출처 미대조 후보는 객관식 출제 대상에서 제외
- **오답/학습 기록**: 독립 localStorage `jgg.kanji.v1`, 한자 퀴즈 중간 답안 sessionStorage `jgg.kanji.quiz.v1`; 기존 문법 `jgg.progress.v1`·`jgg.session.v1` 변경 없음
- **백업**: 한자 기록 독립 JSON 내보내기·가져오기. 기존 문법 JSON 백업은 별도이므로 둘 모두 백업할 것
- **문법 연동**: 실제 제공 중인 문법 단원의 일본어 예문에 등장하는 해당 한자만 클릭해 카드 이동 (홈의 문장 전체 터치 규칙 유지)
- **오프라인**: 5개 한자 데이터 JSON, 한자 JS/CSS를 service-worker v0.2.0 설치 캐시 목록에 포함. 첫 온라인 접속 및 캐시 설치 후 오프라인 사용 예정
- **중요 — 콘텐츠 감수 진행 중**: 한자 데이터 파일명은 .draft.json 유지. 자동 구조 검사는 통과했으나 읽기 검수 대기 92건, 문장 자연스러움·번역·난이도에 대한 전문가 최종 감수와 원본 자료 라이선스 확인은 미완료. 화면에서 감수 중 자료임을 안내.
- **실기기 테스트 미완료**: iPhone Safari/홈 화면 PWA 실제 카드·퀴즈·뒤로가기·새로고침·오프라인·백업 복원 동작은 별도 수동 검증 필요. 저장소 코드 검사는 실기기 테스트가 아님.
- **데이터 출처 참고**: [OpenJLPT](https://github.com/evanclan/OpenJLPT) — CC BY-SA 4.0으로 명시된 한자·어휘 데이터 기반 초안. 기초 한자 100자 목록·한국어 번역·예문 초안은 일본어 문법정원 편집 데이터. 배포물의 원자료별 라이선스 확인 필요.

## 현재 구현 범위

- 6단계 / 60과 학습과정 목록
- **실제 수업 제공: 1과 히라가나 기본, 6과 일본어 어순, 7과 です 문장**
- 제공 단원별 4지선다 **10문제**, 즉시 정답 확인·해설, 80점 완료 기준
- 점수·오답 이력 기기별 로컬 저장, JSON 파일 내보내기 및 복원
- 히라가나·로마자·한국어 의미 표시 옵션, 일본어 음성 합성(기기 지원 시)
- 반응형 파스텔 UI, 시스템 다크모드, PWA 매니페스트와 기본 오프라인 캐시
