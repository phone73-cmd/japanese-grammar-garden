## 한자 학습 v0.2.0 (2026-10-23)

- **학습 메뉴 확장**: 기존 하단 4개 탭 유지, '학습' 화면에 한자 학습 진입 버튼 추가. 기본 100자 + 확장 400자, 전체 5단계×100자
- **한자 카드**: 한자/한국어 뜻, 대표 단어 읽기·뜻, 예문 일본어/히라가나/번역, 뜻·발음 숨김, 일본어 음성(ja-JP, rate 0.85)
- **퀴즈**: 단계별 10문제, 단어 읽기·뜻 4지선다, 즉시 해설 및 80점 통과 기준; `source_reading_match === false`인 단어만 출제 제외. 개별 사전 근거 확인 완료를 의미하지 않음
- **오답/학습 기록**: 독립 localStorage `jgg.kanji.v1`, 한자 퀴즈 중간 답안 sessionStorage `jgg.kanji.quiz.v1`; 기존 문법 `jgg.progress.v1`·`jgg.session.v1` 변경 없음
- **백업**: 한자 기록 독립 JSON 내보내기·가져오기. 기존 문법 JSON 백업은 별도이므로 둘 모두 백업할 것
- **문법 연동**: 실제 제공 중인 문법 단원의 일본어 예문에 등장하는 해당 한자만 클릭해 카드 이동 (홈의 문장 전체 터치 규칙 유지)
- **오프라인**: 5개 한자 데이터 JSON, 한자 JS/CSS를 현재 service-worker 설치 캐시 목록에 포함. 첫 온라인 접속 및 캐시 설치 후 오프라인 사용 예정
- **중요 — 콘텐츠 감수 진행 중**: 한자 데이터 파일명은 .draft.json 유지. 자동 구조 검사는 통과했으나 읽기 후보 92건 1차 검토 완료(87건 개별 사전 근거 미완료), 문장 자연스러움·번역·난이도에 대한 전문가 최종 감수와 원본 자료 라이선스 확인은 미완료. 화면에서 감수 중 자료임을 안내.
- **실기기 테스트 미완료**: iPhone Safari/홈 화면 PWA 실제 카드·퀴즈·뒤로가기·새로고침·오프라인·백업 복원 동작은 별도 수동 검증 필요. 저장소 코드 검사는 실기기 테스트가 아님.
- **데이터 출처 참고**: [OpenJLPT](https://github.com/evanclan/OpenJLPT) — CC BY-SA 4.0으로 명시된 한자·어휘 데이터 기반 초안. 기초 한자 100자 목록·한국어 번역·예문 초안은 일본어 문법정원 편집 데이터. 배포물의 원자료별 라이선스 확인 필요.

- 6단계 / 60과 학습과정 목록
- **실제 수업 제공: 1과 히라가나 기본, 6과 일본어 어순, 7과 です 문장**
