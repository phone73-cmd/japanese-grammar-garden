# 🌸 일본어 문법정원 (Japanese Grammar Garden)

**현재 main: v0.3.11-dev — 한자 연결·검색·분류·추천 학습**

웹앱: https://phone73-cmd.github.io/japanese-grammar-garden/

## 현재 구현

- 문법 **60단원**, 학습 예문 **717개**, 등록 문항 **6,950개**. 등록 문항에는 동일 문장의 읽기·뜻·표현 선택 유형이 포함됩니다. 평가 전용 문장·단어 1,828항목, 여행 대화 27개·108개 발화. 수량은 단원별 합계입니다.
- 히라가나·가타카나 기본 46자씩과 확장 조합. 단원 시험·OX·여러 문장 조립, 학습 확인과 시험 성적을 분리합니다. 일반 시험은 10문제씩 고르며 같은 문장·글자와 최근 출제를 피합니다.
- 한자 **639자 = 기본 500자 + 추가 139자**. 기존 625자 원본과 ID·순서는 유지하고 예문·여행 대화에서 빠졌던 14자만 추가했습니다. 1~5단계 각 100자, 추가 목록은 내부 stage 6입니다.
- 한국 한자음·훈의 출처, 일본어 음독·훈독, 히라가나, 대표 단어·일본어 듣기, 신자체·구자체 비교. 기존 단어 읽기·뜻 및 한국음·음독·훈독·한자 연결 퀴즈, 오답·간격 복습·이어 풀기.
- **통합 검색 2,886항목**: 일본어·히라가나·가타카나·한국어 뜻·문형으로 단원·예문·대화·단어·한자를 검색합니다. 관련 단원과 한자 카드로 이동하고 검색어·분류·결과 범위·이동 전 위치를 기억합니다.
- **품사·표현별 목록**: 명사·동사·い/な형용사·대명사·조사·부사·의문사·접속 표현·문법·수량·인사·회화. 단어는 JMdict의 표기/읽기 제한을 적용한 품사, 기능어·문형은 명시적인 학습용 분류입니다. 5항목은 ‘분류 확인 중’으로 남깁니다. 여러 품사에 포함되는 단어가 있습니다.
- **추천 학습**: 실제 오답·복습 예정일·단원 정답률로 안내합니다. 단원 정답률은 정답/문제 수가 남은 시험·OX 10문제 이상일 때 표시하며 기록이 부족하면 추정하지 않습니다. 문자·한자는 연속 정답과 실제 오답·일정으로 안내합니다. 다음 단원은 실제 단원 시험 통과 기록으로 선택합니다.
- 기존 localStorage·IndexedDB 보호 사본·schema 1 JSON 백업/복원 유지. 새로고침·뒤로가기·명시적인 업데이트·일본어 ja-JP 음성 rate .85 정책 유지.
- 서비스워커 `jgg-v0.3.11-dev`, **47개 필수 자산** 캐시. 검색·분류 데이터와 추가 한자 파일을 포함합니다. 오프라인 검색은 캐시 설치 완료 후 사용합니다. 실제 음성의 오프라인 지원은 기기에 따라 다릅니다.
- 로그인·기기간 동기화·가족 프로필은 현재 제공하지 않습니다. 기기/브라우저별로 학습 기록을 저장합니다.

- 상세 파일·구현·출처·검증 결과: [v0.3.11 보고서](docs/RELEASE-v0.3.11.md), [iPhone 점검표](docs/IPHONE-ACCEPTANCE.md), [현재 데이터 검사](data/LIBRARY-AUDIT-v0.3.11.json).

## 데이터 재생성

고정된 입력 자료에서는 같은 결과를 생성합니다. 새 원본을 받으면 사전 내용·revision이 바뀔 수 있습니다. 원본 자료는 저장소 밖 `SOURCE_DIR`에 두세요.

```sh
python -m pip install -r scripts/requirements-kanji-audit.txt
python scripts/fetch_kanji14_sources.py SOURCE_DIR
python scripts/build_kanji14.py SOURCE_DIR
python scripts/build_library.py SOURCE_DIR
node scripts/audit_library.cjs
node tests/stabilization.cjs
```
