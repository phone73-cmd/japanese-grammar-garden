# 🌸 일본어 문법정원 (Japanese Grammar Garden)

**main 버전: v0.3.6-dev — 콘텐츠·복습 확장 개발본**

웹앱: https://phone73-cmd.github.io/japanese-grammar-garden/

## 현재 구현

- 6단계 × 10단원 = **60단원**, 단원별 10문제 = **600문제**. 기존 1·6·7과 문항 순서/내용은 유지하고 57단원 초안 추가.
- 각 단원 설명·예문·히라가나·로마자·한국어 뜻·정답 해설. 새 단원은 독립 전문가 검수 완료 자료가 아니며 화면에 초안 표시.
- 단원 시험, **OX 연습**, **문장 조립**(입문 1~5과는 글자 순서 맞추기). 조립은 조각을 눌러 선택하고 되돌리기/초기화 가능, 새로고침 복구.
- 문법·한자 **오답만 재시험**, **오늘 복습**. 한 번에 최대 20문제, 1문제도 출제 가능. 정답은 해당 오답 해소, 오답 이력은 지우지 않고 보존.
- 문법은 문항별, 한자는 한자별 정답 연속 횟수에 따라 **1·3·7·14일** 간격 예약. 틀린 항목은 즉시 복습 대상. 복습·OX·조립 기록은 정규 단원 완료 점수와 구분.
- 한자 **500자·691단어·500예문**. 공식 JMdict의 표기/읽기 및 읽기 제한을 대조하여 **92/92 후보, 691/691 단어 항목 일치**. 예문은 AI 편집 1차 점검, 7건 수정. 원어민·독립 전문가의 최종 감수는 미완료이며 .draft.json 유지.
- 기존 localStorage 저장 키를 그대로 사용하고, 문법·한자 진행 상태는 sessionStorage와 로컬 복구 사본 유지.
- **IndexedDB 보호 사본** 추가. 기존 기록이 있으면 초기 사본을 만들고, 성공적으로 기록을 저장할 때 사본도 갱신. ‘보호 사본 내보내기’ 파일을 기존 JSON 가져오기로 복원. 기존 키를 지우거나 기본 저장소를 이전하지 않음.
- 버전별 오프라인 캐시, 명시적인 업데이트 적용, 학습 상태 보존. 새 수업·조립·보호 사본 모듈과 자료 출처 화면을 캐시.
- Apple 홈 화면용 180px PNG 및 PWA 192/512px PNG 아이콘. 실제 iPhone 설치 결과는 미확인.
- 로그인·Firebase·기기간 클라우드 동기화 없음.

## 검증 범위

`node tests/stabilization.cjs` — **23개 검사 통과**. 60단원/600문항 생성·렌더링·완료, 60개 조립 목표, 혼합 단원 오답·일정, 1문제 한자 복습, 저장 실패·재시도·중복 방지, 뒤로가기·복구, IndexedDB 대체 불가 시 기본 저장 유지·사본 직렬 저장, 필수 캐시 설치를 Node 모의 환경에서 검사합니다.

이 결과는 iPhone Safari/PWA의 터치·스와이프·음성·비행기 모드·강제 종료 테스트를 대신하지 않습니다. 실제 브라우저 확인 결과는 배포 후 별도로 기록하며, [실기기 인수 검사](docs/IPHONE-ACCEPTANCE.md)는 현재 미확인입니다.

- `jgg.kanji.v1`, `jgg.kanji.quiz.v1`, `jgg.kanji.quiz.backup.v1`

기존 진도·오답 배열·ID·문제 인덱스는 유지합니다. 복습 일정과 결과 종류는 필드를 추가하는 방식입니다. 문법/한자 JSON은 각각 내보내 보관하세요. 새 보호 사본은 같은 브라우저 안의 사본이므로 기기 밖 백업을 대체하지 않습니다.

## 출처·재현

- [자료 출처와 검수 범위](docs/CONTENT-SOURCES.md), [앱 출처 화면](sources.html)

- 한자 파생 데이터: OpenJLPT와 EDRDG 출처를 고지하고 **CC BY-SA 4.0** 적용. 세부 원전 조건은 문서 링크 참조.
