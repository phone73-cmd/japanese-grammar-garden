# 🌸 일본어 문법정원 (Japanese Grammar Garden)

**배포 버전: v0.1.1 (초기 개발본)**

- 웹앱: https://phone73-cmd.github.io/japanese-grammar-garden/
- 독립형 일본어 문법 학습 PWA · iPhone Safari 우선
- Firebase, Google 로그인, 클라우드 동기화 **없음**
- 기존 일본어 단어장 프로젝트와 코드·저장 데이터 공유 **없음**

## 현재 구현 범위

- 6단계 / 60과 학습과정 목록
- **실제 수업 제공: 1과 히라가나 기본, 6과 일본어 어순, 7과 です 문장**
- 제공 단원별 4지선다 **10문제**, 즉시 정답 확인·해설, 80점 완료 기준
- 점수·오답 이력 기기별 로컬 저장, JSON 파일 내보내기 및 복원
- 히라가나·로마자·한국어 의미 표시 옵션, 일본어 음성 합성(기기 지원 시)
- 반응형 파스텔 UI, 시스템 다크모드, PWA 매니페스트와 기본 오프라인 캐시

## 추가 개발 및 검증 필요

- 미작성 57개 단원과 문법·예문·문제 콘텐츠 검수
