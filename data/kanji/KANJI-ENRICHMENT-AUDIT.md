# 한자 625자 전수 대조 · v0.3.8-dev

## 검증 범위
기존 625자 ID·단계·순서·단어·예문 파일을 변경하지 않고 연결 데이터를 생성합니다.
KANJIDIC2 공식 자료의 korean_h·ja_on·ja_kun을 전수 대조했습니다.
한국식 훈은 위키낱말사전의 명시적인 훈·음 필드와 예외 항목의 한국 한자 사전 개별 조회를 사용합니다. 잘못된 필드는 그대로 채택하지 않습니다. 짧은 훈·음 사실 정보 외에 사전의 긴 정의·예문·미디어는 복제하지 않았습니다. 사전 간 대조·출처 연결이며, 공인 기관 인증 및 전문가 전체 교차 감수 완료를 의미하지 않습니다.
미확인 값은 빈 목록으로 유지하고 출제하지 않습니다.
KANJIDIC2의 이체자 관계는 한국 정자체 확정과 구별합니다. 한국 표기 관계는 별도 명시 출처가 있는 경우만 표시합니다.

## 재현
1. 공식 KANJIDIC2 및 JMdict_e 압축 파일, 위키낱말사전 API revision 스냅샷을 확보합니다.
2. `python scripts/audit_korean_kanji.py SOURCES/kanjidic2.xml.gz`
3. `pip install -r scripts/requirements-kanji-audit.txt`
4. `python scripts/build_kanji_enrichment.py SOURCES`
원문 압축 파일 SHA-256, 사전 날짜, 문서별 revision·고유 링크는 결과 JSON에 기록합니다.
한국어 뜻이 있는 기존 단어 및 위키낱말사전 일본어 파생어, JMdict 영어 의미에 근거해 작성한 한국어 번역을 사용합니다. 모든 추가 표기/읽기를 JMdict 제한 조건까지 확인하며 원어민 전체 번역 감수는 미완료입니다. 기존 단어 번역은 이전 편집 상태를 유지합니다.
대표 단어가 2개 미만인 글자는 검증되지 않은 단어로 채우지 않습니다.
