# 문장 속 추가 한자 125자 · v0.3.5-dev

- 기준일 2026-10-24. 기존 기본 5단계 500자 파일은 변경하지 않았다.
- 문법 60과 예문에 수록되지 않았던 한자 40자, 한자 500자 예문에 수록되지 않았던 한자 108자의 합집합 125자를 보충했다. 두 범위는 23자가 겹친다. 모든 예문에 등장하는 서로 다른 한자는 625자이며 전체를 연결한다.
- 여행 관련 글자를 우선하는 편집 순서이며 빈도 통계 순위는 아니다. 기본 단계 1~5는 보존하고 내부 stage 6, 안정적인 extra-유니코드 ID를 사용한다. 저장 키와 기존 레코드는 유지하고 추가 ID 기록만 같은 저장 구조에 누적한다.
- 각 항목: 글자 뜻, 대표 단어·읽기·한국어 뜻, 기존 앱에서 재사용한 관련 예문·읽기·번역. 독립 원어민 검수는 미완료이며 draft 상태이다. 글자 뜻은 대표 의미 요약이며 모든 의미·음훈의 목록이 아니다. 읽기는 대표 단어와 예문을 기준으로 표시한다.
- 대표 단어 125항목은 JMdict에서 표기/읽기 쌍 125/125 일치(re_restr 적용). 중복 대표 단어가 있으므로 고유 어휘 125개라는 뜻은 아니다. 사전 의미를 복제하지 않았다.
- 사전 원본: https://www.edrdg.org/pub/Nihongo/JMdict_e.gz
- 사전 이용 조건: https://www.edrdg.org/edrdg/licence.html
- 사전 파일 SHA-256: b45f780bd76b56099fe36f1a6d12c7900db687592f3782280bd924dd7f3b2127
- 생성 입력: extra-words.tsv 및 기존 grammar-lessons.js/index.html/kanji-stage-1..5 JSON.
- 재생성: `python scripts/build_extra_kanji.py /path/to/JMdict_e.gz`
- 각 word의 dictionary_entry_sequences가 일치한 사전 항목 근거다. 한국어 의미와 예문 전체는 사전이 검증한 것으로 표시하지 않는다.
